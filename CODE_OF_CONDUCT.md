# Code of Conduct

TaxDisc aims to be a respectful, practical place to collaborate.

- Be considerate of different experience levels, languages, and accessibility needs.
- Discuss code and behavior directly; avoid personal attacks, harassment, threats, discriminatory language, and unwanted contact.
- Respect privacy. Do not post private file paths, scan records, credentials, or personal information without permission.
- Keep feedback constructive and relevant. Disagreement is welcome; intimidation and repeated disruption are not.

Maintainers may edit or remove inappropriate content and limit participation when needed. Enforcement should be proportionate and consider context. This policy applies to repository issues, pull requests, discussions, and other project-maintained spaces.

For a conduct concern, request a private contact from the [maintainer](https://github.com/Taxperia) without exposing another person's sensitive information in a public report. Security vulnerabilities follow [SECURITY.md](SECURITY.md).
